# 电商购物商城系统使用说明

## 系统概述

本系统是一个基于 Python+Django 后端和 Vue 3 前端的完整电商购物商城系统，风格类似于京东、淘宝等主流电商平台，包含了完整的电商功能。

## 技术栈

### 后端
- Python 3.8.2
- Django 3.2.23
- Django REST Framework
- JWT 认证
- SQLite 数据库
- Redis 缓存

### 前端
- Vue 3
- Vite
- Bootstrap 5
- Pinia (状态管理)
- Vue Router

## 系统功能

### 前端功能
1. **首页**：轮播图、商品分类导航、热门商品、新品上市、推荐商品
2. **商品分类**：商品列表、价格筛选、排序功能、分页
3. **商品详情**：商品图片、基本信息、购买选项、商品详情、用户评价、规格参数、相关商品
4. **搜索**：搜索框、搜索结果展示、筛选和排序
5. **购物车**：商品列表、数量调整、全选功能、价格计算、结算
6. **结算**：收货地址选择、支付方式选择、商品信息确认、订单提交
7. **用户认证**：登录、注册、密码重置
8. **个人中心**：用户信息、订单管理、地址管理、收藏管理、账户设置
9. **订单管理**：订单详情、订单状态更新、支付、确认收货

### 后端功能
1. **用户管理**：注册、登录、个人信息管理
2. **商品管理**：商品列表、商品详情、分类管理
3. **购物车管理**：添加、删除、修改商品数量
4. **订单管理**：创建订单、订单状态更新、订单查询
5. **地址管理**：添加、编辑、删除收货地址
6. **支付管理**：支付接口集成
7. **评价管理**：商品评价

## 运行环境准备

### 后端环境
1. 安装 Python 3.8.2
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 配置数据库：
   - 默认使用 SQLite，无需额外配置
   - 如需使用 MySQL 或 PostgreSQL，请修改 settings.py 中的数据库配置

### 前端环境
1. 安装 Node.js (推荐 v16+)
2. 安装依赖：
   ```bash
   cd frontend
   npm install
   ```

## 运行步骤

### 1. 启动后端服务器

```bash
# 进入项目根目录
cd ecommerce

# 执行数据库迁移
python manage.py makemigrations
python manage.py migrate

# 创建超级用户（可选）
python manage.py createsuperuser

# 启动开发服务器
python manage.py runserver
```

后端服务器默认运行在 http://localhost:8000

### 2. 启动前端开发服务器

```bash
# 进入前端目录
cd frontend

# 启动开发服务器
npm run dev
```

前端开发服务器默认运行在 http://localhost:3000

### 3. 访问系统

在浏览器中打开 http://localhost:3000 即可访问电商系统前端页面。

## 系统使用流程

### 1. 浏览商品
- 在首页浏览推荐商品、热门商品和新品
- 通过分类导航浏览特定分类的商品

- 点击商品进入详情页

- 在购物车页面查看已添加的商品
- 调整商品数量
- 选择要结算的商品
- 点击结算按钮进入结算页面

### 4. 结算下单
- 选择收货地址
- 选择支付方式
- 确认订单信息
- 提交订单

### 5. 支付
- 选择支付方式
- 完成支付流程

### 6. 订单管理
- 在个人中心查看订单列表
- 查看订单详情
- 确认收货
- 评价商品

### 7. 个人中心
- 查看和修改个人信息
- 管理收货地址
- 查看收藏的商品
- 修改密码等账户设置

## 注意事项

1. **跨域问题**：前端已配置 API 代理，将 `/api` 前缀的请求代理到后端服务器
2. **认证方式**：使用 JWT 进行用户认证，登录后会将 token 存储在本地存储中
3. **数据库**：默认使用 SQLite，生产环境建议使用 MySQL 或 PostgreSQL
4. **缓存**：使用 Redis 进行缓存，提高系统性能
5. **安全**：密码使用加密存储，敏感信息传输使用 HTTPS

## 常见问题解决

### 1. 后端启动失败
- 检查 Python 版本是否正确
- 检查依赖是否安装完整
- 检查数据库配置是否正确

### 2. 前端无法连接后端
- 检查后端服务器是否启动
- 检查 API 代理配置是否正确
- 检查网络连接是否正常

### 3. 登录失败
- 检查用户名和密码是否正确
- 检查 JWT 配置是否正确
- 检查后端认证接口是否正常

### 4. 商品无法添加到购物车
- 检查商品是否存在
- 检查购物车 API 是否正常
- 检查用户是否登录

### 5. 订单提交失败
- 检查收货地址是否完整
- 检查支付方式是否选择
- 检查后端订单 API 是否正常

## 生产环境部署

### 后端部署
1. 使用 Gunicorn 作为 WSGI 服务器
2. 使用 Nginx 作为反向代理
3. 配置 HTTPS
4. 使用 MySQL 或 PostgreSQL 数据库
5. 配置 Redis 缓存

### 前端部署
1. 构建生产版本：`npm run build`
2. 将构建产物部署到 Nginx 或 Apache 服务器
3. 配置静态文件服务
4. 配置 API 代理到后端服务器
